Jalan keledai

Delapan trik yang bikin soal UTS kelar tanpa mikir lama.

1
ID = String, bukan Integer

NIM, memberID, kode booking. Kalau Integer, nol depan hilang.

2
Tarif = konstanta

Rate, denda, batas hari. Kata kunci GLOBAL CONSTANT.

3
Trace: kondisi dulu, angka belakangan

Tulis TRUE/FALSE tiap IF/WHILE, baru isi nilai variabel.

4
Cek batas < vs <=

count < 4 = 3 putaran. count <= 4 = 4 putaran. Ini jebakan favorit.

5
Akumulator wajib total = total + x

Kalau total = x, nilai lama ketimpa. Jawaban jadi aneh.

6
Boolean: kurung menang

Urutan NOT → AND → OR. Ada kurung, kerjain kurung dulu.

7
Rata-rata: cek count > 0

Bagi nol = crash. Selalu lindungi sebelum total/count.

8
Value vs REF

Value = salinan (asli aman). REF = alias (asli berubah).

Scope: IPO, data type, variabel vs konstanta, decision + Boolean, repetition, function + validasi, file & menu. UML di luar scope MID.

Topik 2

Variabel & Konstanta

Variabel

Nilainya berubah: total, count, temperature, duration.

Konstanta

Nilai mati: HOURLY_RATE, tarif denda, batas 14 hari.

2A Format deklarasi dosen

DECLARE GLOBAL CONSTANT Integer HOURLY_RATE = 12000
DECLARE Real total
DECLARE Integer count
SET total = 0
SET count = 1
  • Tipe di depan, nama di belakang.
  • Konstanta pakai CONSTANT, bukan SET.
  • Dipakai lintas modul → GLOBAL.

Topik 5

Function & Parameter

5A Header fungsi

FUNCTION Real CalculateRentalFee(Integer hoursRented)
    IF hoursRented <= 0 THEN
        RETURN -1
    END IF
    RETURN hoursRented * HOURLY_RATE
END FUNCTION

MODULE Main()
    DECLARE Integer duration
    INPUT duration
    DISPLAY CalculateRentalFee(duration)
END MODULE
  • Return type di depan nama, tanpa RETURNS di belakang.
  • Formal parameter = hoursRented (di header).
  • Actual argument = duration (dikirim saat CALL).

5B Value vs REF

MODULE ChangeByReference(Integer REF number)
    SET number = number + 5
END MODULE
KirimVariabel asli
by valuetetap (salinan)
REFikut berubah (alias)
Topik 6

Validasi, File, Menu

6A Loop validasi + sentinel

INPUT humidity
WHILE humidity <> -1 DO
    IF humidity < 0 OR humidity > 100 THEN
        DISPLAY "Invalid humidity"
    ELSE
        SET total = total + humidity
        SET count = count + 1
    END IF
    INPUT humidity
END WHILE

IF count > 0 THEN
    DISPLAY total / count
ELSE
    DISPLAY "No readings"
END IF
  • Data invalid jangan masuk total/count.
  • Sentinel (-1) penanda stop, bukan data.
  • Cek count > 0 sebelum bagi.

6B Menu pakai CASE

DISPLAY "1. Borrow  2. Return  3. Report  0. Exit"
INPUT choice
CASE choice OF
    1: CALL BorrowBook()
    2: CALL ReturnBook()
    3: CALL ShowReport()
    0: DISPLAY "Bye"
END CASE

Pola: tampil → input → validasi pilihan → panggil modul → balik ke menu.
