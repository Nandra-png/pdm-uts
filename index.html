IPO & Tipe Data pasti keluar

Nentuin input, proses, output — plus milih tipe yang bener

Tiga baris, langsung. Jangan narasi panjang.

Contoh jawaban
INPUT   memberID, startHour, visitorCount
PROCESS validasi 8 <= startHour <= 19
        cek ketersediaan pod
OUTPUT  status diterima / ditolak, kode konfirmasi

Variabel & Konstanta format dosen

Salah nulis deklarasi = poin hilang walau logikanya bener
Deklarasi
DECLARE GLOBAL CONSTANT Integer HOURLY_RATE = 12000
DECLARE Real total
DECLARE Integer count
SET total = 0
SET count = 1
  • Tipe di depan, nama variabel di belakang.
  • Konstanta pakai CONSTANT, bukan SET.
  • Dipakai lintas modul → tambah GLOBAL.
  • Variabel: total, count, temperature, duration. Konstanta: rate, denda, batas hari.
Jebakan: nilai yang cuma dipakai sekali dan nggak pernah berubah tetap boleh variabel — tapi kalau angkanya tarif/aturan, wajib konstanta.

Kombinasi Boolean

   AND NOT isRestricted THEN

END IF
IF atau CASE?
BentukPakai kalau
IF / ELSEkondisi benar-salah, kombinasi Boolean
CASEpilih satu dari banyak kategori (menu 1–8)
Kalau disuruh trace: tulis nilai tiap bagian dulu — cardValid=T, isStaff=F, trainingDone=T → F OR T = T — baru gabungin.

Function & Parameter tulis sendiri

Return type di depan, tanpa kata RETURNS
Header fungsi
FUNCTION Real CalculateRentalFee(Integer hoursRented)
    IF hoursRented <= 0 THEN
        RETURN -1
    END IF
    RETURN hoursRented * HOURLY_RATE
END FUNCTION

MODULE Main()
    DECLARE Integer duration
    INPUT duration
    DISPLAY CalculateRentalFee(duration)
END MODULE
  • Formal parameter = hoursRented (di header fungsi).
  • Actual argument = duration (dikirim saat dipanggil).
  • Validasi di dalam fungsi: nilai aneh → RETURN -1.
Value vs REF
MODULE ChangeByReference(Integer REF number)
    SET number = number + 5
END MODULE
KirimVariabel asli
by valuetetap (salinan)
REFikut berubah (alias)

Validasi, File & Menu gabungan

Loop sentinel + CASE menu — pola yang sama terus
Loop validasi + sentinel
INPUT humidity
WHILE humidity <> -1 DO
    IF humidity < 0 OR humidity > 100 THEN
        DISPLAY "Invalid humidity"
    ELSE
        SET total = total + humidity
        SET count = count + 1
    END IF
    INPUT humidity
END WHILE

IF count > 0 THEN
    DISPLAY total / count
ELSE
    DISPLAY "No readings"
END IF
  • Data invalid jangan masuk total / count.
  • Sentinel (−1) penanda stop, bukan data.
  • Cek count > 0 sebelum bagi.
Menu pakai CASE
DISPLAY "1. Borrow  2. Return  3. Report  0. Exit"
INPUT choice
CASE choice OF
    1: CALL BorrowBook()
    2: CALL ReturnBook()
    3: CALL ShowReport()
    0: DISPLAY "Bye"
END CASE
Pola menu: tampil → input → validasi pilihan → panggil modul → balik ke menu.
